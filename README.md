# نبض | SocialPulse 2

منصة عربية RTL لرصد **منشورات Bluesky العامة**، ومشاهدة الردود والوسائط، وتحليل العينة وتصديرها. طُوّرت من الأرشيف المرفق مع الحفاظ على ملفات أنطولوجيا المهام وتشغيل Python المحلي.

## الوظائف

- البحث الحقيقي مع ترتيب الأحدث/الأكثر صلة وفلاتر العربية والإنجليزية والتاريخ، وترقيم الصفحات وإزالة التكرار (حتى 500 منشور للجلسة).
- مؤشرات الحسابات والتفاعل والانطباع، ومخطط زمني وأبرز المتحدثين؛ جميعها للعينة المعروضة فقط.
- تصفية الانطباع والوسائط، وعرض الصور وروابط الفيديو والمنشور الأصلي والردود العامة (حتى 3 مستويات و80 ردًا).
- تحليل قاموسي عربي/إنجليزي يراعي حدود الكلمات وبعض النفي، مع إظهار الكلمات المطابقة وحدود الدقة. **ليس نموذج AI ولا استطلاع رأي عام.**
- تصدير CSV متوافق مع UTF-8 مع تحييد صيغ الجداول، وJSON يتضمن المصدر والبحث والفلاتر وتوقيت الجمع.
- حفظ عبارات البحث محليًا في المتصفح وحذفها. لا قاعدة بيانات للمنشورات ولا جمع خلفي.
- واجهة متجاوبة قابلة للتنقل بلوحة المفاتيح، وحالات انتظار/فراغ/خطأ واضحة، ولا نتائج مصطنعة عند تعطل المصدر.

## تشغيل محلي: Python 3.10+

```bash
python server.py
```

افتح http://localhost:8787. لا حزم خارجية. الخادم المحلي يستمع على localhost ويقدّم الملفات العامة فقط.

## تشغيل Worker: Node 22+

```bash
npm test
npm run build
npm run validate
npm run dev
```

افتح http://localhost:3000. لا يلزم تثبيت اعتماديات. البناء يضم الواجهة ووحداتها داخل ملف Worker مستقل في `dist/server/index.js`.

## الاختبارات

```bash
node --test tests/*.test.mjs
python -m unittest discover -s tests -p 'test_*.py'
node scripts/build.mjs
node scripts/validate-artifact.mjs
```

اختبارات العقد تغطي المدخلات والتواريخ والنفي وحدود الكلمات وتكرار الصفحات وتصدير CSV، وتمرير الفلاتر، وفشل المصدر، والردود و429 وحدود الطلبات. الاختبارات المحاكاة لا تُعد إثباتًا لاتصال Bluesky الحي.

## API

- `GET /api/status`: صحة التطبيق فقط؛ `upstream: not-checked` لا تعني أن المصدر متصل.
- `GET /api/search?q=coffee&sort=latest&lang=en&since=2026-10-01&until=2026-10-30&limit=40&cursor=...`: البحث، `cursor` للصفحة التالية.
- `GET /api/thread?uri=at%3A%2F%2F...`: ردود عامة.

`since` و`until` تواريخ ISO بتوقيت UTC؛ يشمل `until` يوم النهاية كاملًا بتحويله إلى بداية اليوم التالي في طلب Bluesky. المصدر قد يفرض قيود فهرسة أو مصادقة أو حدود طلبات؛ الخطأ يعرض بصراحة دون تحويله إلى نتائج فارغة ناجحة.

## بنية الملفات

|---|---|
| `index.html`, `styles.css`, `app.js` | الواجهة والتفاعل |

| `docs/DEVELOPMENT.md` | التصميم وخطة التطوير |

## الخصوصية والقيود

البيانات عامة فقط. تُرسل عبارة البحث إلى خادم التطبيق ثم Bluesky، وتُحمّل الصور من عناوينها العامة. قد تحتفظ البنية المستضيفة بسجلات تشغيل؛ التطبيق لا يخزّن المنشورات. حدود الطلبات 30 طلب بيانات/دقيقة لكل IP في Python، وتقريبية لكل نسخة تشغيل في Worker؛ ليست حصة موزعة. لا مفاتيح API أو دفع أو تكامل شبكات أخرى. حفظ البحث لا يعني مراقبة دورية. دقة المشاعر غير مقاسة وقد تخطئ مع النفي المركب واللهجات والسخرية. راجع المنهجية داخل الواجهة.
